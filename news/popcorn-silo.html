Popcorn Silo: A Simple Place for Your Files

Upload and organize files, then choose which ones to share.

November 13, 2026

Popcorn Silo is a file upload and management utility by Daniel McKeown. It offers a simple place to keep files organized and share them with others.

Manage and share

Users can create an account to upload, download, rename, and delete files. Each file can be kept private or marked as shared, with a permalink page for access. The front page displays the most recent shared file.

Run your own silo

Popcorn Silo is written in plain PHP, with no Composer dependencies or build step. It can store account and file information in local JSON files or use a MySQL database. Administrators can close registration or require an invite code.

Built in the open

The source code is available on GitHub under the ISC License, along with setup instructions and notes for deploying the app.
